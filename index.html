Operations Manual

To Start:

Make a Tavily Account at app.tavily.com to get a free api key (1000 credits/month)

Initializing API & Location

Paste the API key into the API field & Use the Geographic Context (e.g., Ahmedabad) to help the AI narrow down local business entities for higher accuracy.

Initializing Source Cell & End Cell:

The Source Cell (e.g., A2) is where your list of names begins & End Cell (Optional) is where you want that list to end. If left empty, the tool reads vertically until it hits three consecutive empty cells.

Dynamic Field Mapping

Check the modules you need and assign a Column Letter for each. The results will be placed in that column, aligned perfectly with the source row.

Smart Persistence Logic

The system uses Intelligence Skipping. It scans your Excel file first; if a cell already contains data, it is marked as CACHED and the API call is skipped to save you credits. To retry missing data, simply press initialise extraction (you can even change the input parameters like the api key, place too)

Live Mission Monitoring

  • ETC: Real-time countdown based on thread latency.
  • Overview: View cumulative session data, human time saved, and data composition.
  • Live Export: Click at any point to download the current state of your workbook.

To Save

  • Live Export: Instantly generate and download your enriched dataset as a professional Excel (.xlsx) file.
  • Copy Snapshot: This copies the whole spreadsheet (including all your original data & updated data) so you can paste it directly.
