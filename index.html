Complete Setup Guide

📋 Step 1: Get Your Tavily API Key

1. Visit app.tavily.com and create a free account

2. Navigate to your API dashboard after signing in

3. Copy your API key (starts with tvly-)

4. Paste it into the "API Key" field in ScrapeX

Free Tier: 1,000 searches/month.

Smart Search: ScrapeX automatically uses "basic" search (1-2 results) for LinkedIn/Website/Social and "advanced" search (3-5 results) for Email/Phone/Address to optimize accuracy and cost.

Tip: The "Session Tavily" counter tracks your usage and resets when you enter a new API key.

📊 Step 2: Upload Your Excel File

  • Enter The Starting Source Cell (Ex: If Company's Names Are In Column A, And First Entry Is In Row 3, Enter A3
  • Enter End Cell (Optional), If Left Unfilled, It Terminates After It Finds 3 Blank Spaces)

⚙️ Step 3: Configure ScrapeX Settings

Geographic Context: Enter city/region where companies are located (e.g., "San Francisco, CA" or "London, UK"). This significantly improves accuracy.

Source Range:

  • Start Cell: First cell with company name (e.g., A3 if rows 1-2 are headers)
  • End Cell: Leave blank to auto-detect end, or specify (e.g., A50) to limit scope
  • You'll see a preview showing first and last company detected

Worker Threads: Number of parallel API calls (default: 6). More threads = faster but higher API rate. Stay at 6 unless you have API rate issues.

🎯 Step 4: Select Extraction Modules

Check the modules you want to extract. Each module makes 1 API call per unique company:

  • Address: Physical street address
  • LinkedIn: Company LinkedIn page URL
  • Email: Primary contact/general email
  • Phone: Main business phone number
  • Socials: Instagram handle (modify prompt for Twitter/Facebook)
  • Website: Official company website
  • Founder: Name(s) of company founder(s)

The column letters (B, C, D...) specify where each field will be written in your Excel file.

💰 Step 5: Review Mission Briefing

Before clicking Initialize, check the estimates:

  • Companies to Process: Unique companies detected (duplicates are auto-cached)
  • Duplicate Rows: Rows with repeated company names (these cost 0 API calls)
  • Data Fields Selected: Number of extraction modules you've enabled
  • Total Extraction Tasks: Companies × Selected Fields = max API calls we'll make
  • Est. Tavily Usage: Smart calculation based on search depth (basic: ~1.5 results, advanced: ~3.5 results)
  • Est. Time: Based on ~2.5s per call with your thread count

⚠️ Important: Make sure Est. Tavily Usage fits within your monthly quota!

💡 Optimization Tip: The more you use cache, the fewer API calls you need. Re-run with different field selections to maximize savings.

🚀 Step 6: Run Extraction

1. Click Initialize to start

2. Watch the Command Deck for real-time metrics:

  • Session Tavily: Total Tavily searches used with current API key (persists across runs, resets when you change API key)
  • Duplicates: Number of duplicate company entries automatically skipped (saving API calls)
  • Not Found: Fields where data couldn't be located (normal for 10-20% of requests)
  • Time Left: Estimated time to completion (improves accuracy as extraction progresses)

3. Use controls:

  • Pause/Resume: Temporarily stop/continue extraction
  • Auto-Scroll: Toggle feed auto-scrolling to active row
  • Stop: Halt extraction completely
  • Stats: View detailed run overview with module-wise efficiency

💾 Step 7: Export Your Results

Option 1 - Download Excel: Click Export to download complete Excel file

Option 2 - Copy to Clipboard: Click Copy to copy as TSV (paste directly into Excel/Google Sheets)

Note: Both options work during or after extraction!

🎨 Visual Indicators

  • Border Glow: Cyan = excellent (90%+ success), Amber = warning (70-90%), Red = critical (<70%)
  • Shimmer Effect: Fields currently being fetched from API
  • Status Badges: "Extracted" (new data), "Cached" (from previous run), "DUP" (duplicate row)

💡 Pro Tips

  • Run once to build cache, then re-run with more modules—duplicates cost 0 API calls!
  • Geographic Context is crucial for accuracy—don't skip it! Use specific city names for best results.
  • Check module efficiency in Stats—if <70%, try improving geographic context or company names
  • LinkedIn/Website/Social use "basic" search (cheaper), while Email/Phone/Address use "advanced" (more thorough)
  • Session Tavily counter persists across runs and only resets when you change your API key
  • For best geo-accuracy, include both city and state/country (e.g., "Ahmedabad, Gujarat" not just "Ahmedabad")
  • Check "Run Overview" after extraction for detailed module-wise performance and time saved
